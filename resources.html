Certifications

GitHub certifications are delivered through Microsoft Learn. Each exam is 100 minutes and costs USD 99 (price varies by country). Certifications are valid for two years, except GitHub Foundations, which does not need renewal.

CertificationExamLevelGood for
GitHub FoundationsGH-900BeginnerEveryone new to GitHub
GitHub CopilotGH-300IntermediateDevelopers and champions in a Copilot pilot
GitHub Advanced SecurityGH-500IntermediateAppSec engineers and security champions
GitHub ActionsGH-200IntermediatePlatform and DevOps engineers
GitHub AdministrationGH-100IntermediateGitHub and enterprise administrators (English only)

Glossary

TermMeaning in this workshop
Agent modeCopilot in the IDE taking a multi-step task: choosing files, editing, running commands (with your approval) and iterating.
Plan modeA read-only planning agent that proposes an implementation plan before any code changes.
Copilot cloud agentFormerly the coding agent. Works in the background in a cloud environment and returns a pull request for human review.
GitHub AI CreditsThe unit of Copilot usage billing since 1 June 2026; 1 credit = USD 0.01.
Custom instructionsMarkdown files (for example .github/copilot-instructions.md) that tell Copilot your project's rules.
Custom agentAn agent profile (.github/agents/NAME.agent.md) with its own instructions and tools.
MCPModel Context Protocol: the standard way to give Copilot tools and context from other systems.
Copilot AutofixAI-generated fix suggestions for code scanning alerts.
Agentic autofixAssigning code scanning alerts to Copilot, which explores, fixes, rechecks with CodeQL and opens a draft pull request.
Push protectionBlocks commits that contain detected secrets before they reach the repository.
RulesetBranch or tag rules (reviews, checks, code scanning results) enforced for humans and agents alike.
EnvironmentA deployment target in GitHub Actions with protection rules such as required reviewers.
OIDCOpenID Connect: GitHub Actions requests a short-lived token that a cloud trusts, so no long-lived cloud secret is stored.
EMUEnterprise Managed Users: GitHub accounts created and controlled by your identity provider.
GHE.comGitHub Enterprise Cloud with data residency, on a dedicated subdomain.
