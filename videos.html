Overview / Demo videos

Demo videos

Two short, simulated walkthroughs of the workshop demos, with a chapter for every step. Watch them before the day, use them to recap afterwards, or keep them as a backup if the live environment fails.

What "simulated" means here

The steps, settings and file names follow GitHub Docs and the runbooks on this site. The screens are simplified re-creations of GitHub, VS Code and Azure, and the AI output is illustrative: real Copilot output differs from run to run. Every frame carries a Simulated walkthrough label. If you play a video in front of the room, say so.

How these videos are made

  • Each video is a scripted HTML replay of the demo. The same replay runs in your browser as the interactive replay, where you can pause, step through chapters and change the speed.
  • The MP4 files were rendered by a GitHub Actions run for this repository: it plays the replay frame by frame in headless Chrome and encodes it with ffmpeg (1920 × 1080, 25 frames per second). tools/render-video.mjs in the repository does the same on any machine with Node.js, Chrome and ffmpeg. There is no audio: the captions carry the story, so a presenter can talk over the video.
  • Sources for each step are the GitHub Docs and Microsoft Learn pages listed on the session pages.
