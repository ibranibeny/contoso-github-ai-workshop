Overview / Demo videos

Demo videos

Simulated screen recordings of the four demo sessions, with a chapter for every step. Watch them before the day, use them to recap afterwards, or keep them as a backup if the live environment fails.

What "simulated" means here

Each video re-creates the demo as a screen recording: GitHub in the browser, VS Code, the terminal and the Azure portal. The steps, prompts, settings and file names follow the runbooks on this site and GitHub Docs. The screens are re-creations and the AI output is illustrative: real Copilot output differs from run to run. The taskbar in every frame carries a Simulated demo label. If you play a video in front of the room, say so.

How these videos are made

  • Each video is a scripted HTML replay of the demo. The same replay runs in your browser as the interactive replay (linked under each video), where you can pause, step through chapters and change the speed.
  • The MP4 files were rendered by a GitHub Actions run for this repository: it plays the replay frame by frame in headless Chrome and encodes it with ffmpeg (1920 × 1080, 25 frames per second). tools/render-video.mjs in the repository does the same on any machine with Node.js, Chrome and ffmpeg. There is no audio: the captions carry the story, so a presenter can talk over the video.
  • Sources for each step are the GitHub Docs and Microsoft Learn pages listed on the session pages.
